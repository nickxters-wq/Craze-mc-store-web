ANDROID + GITHUB UPLOAD
1. Extract this ZIP on your phone.
2. Open your GitHub repository in Chrome. Turn on Desktop site if needed.
3. Upload the contents of this folder to the ROOT of the repository (not the ZIP itself).
4. Keep the assets folder and all four image files together. Do not rename them unless you also update the paths in index.html/style.css.
5. Commit the changes.
6. If your Vercel project is connected to this GitHub repository, Vercel should automatically deploy the new commit.
7. Open Vercel Deployments and wait for Ready, then refresh your website.

If replacing an existing site, back up your current files first. Upload/replace index.html, style.css, script.js and the assets folder with these versions.
